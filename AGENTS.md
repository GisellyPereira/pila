# Preferências da Giselly

- Em projetos React Native com Expo, verificar e usar o SDK estável mais recente disponível. Atualizar React, React Native e os módulos Expo para as versões compatíveis com esse SDK.
- A usuária sempre executa o projeto. Apenas modificar arquivos e atualizar dependências quando solicitado. Não iniciar Expo, servidores, emuladores, builds, exports nem verificações que executem o projeto. Os comandos de início fornecidos à usuária devem limitar o Metro a um worker.
