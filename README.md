# PILA — Controle Financeiro Gamificado

App mobile brasileiro de finanças pessoais com mascote, humor e gamificação.
"Duolingo das finanças" — personalidade e tom de voz como principal diferencial.

## Mascote
**Jota** — moeda antropomórfica cartoon, amigo sincerão, comenta/zoa/celebra os gastos do usuário.

## Estrutura do projeto
- `docs/` — briefing, tom de voz, gamificação, telas
- `design/` — identidade visual, design system
- `assets/` — referências, mockups, exports do Figma

## Status
Fase de concepção/design para portfólio. Foco em Figma, tom de voz do Jota e sistema de gamificação.

## Público-alvo
Brasileiros 22–40 anos, urbanos, conectados, cansados de apps financeiros sem alma.
