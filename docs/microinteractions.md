# Microinterações — Jota Vivo

Princípio: Jota **nunca está parado**. Sempre uma microanimação de base (respirar, piscar, balançar).

## Reações por evento

| Evento | Reação do Jota |
|---|---|
| Abrir app | Acorda, boceja, se espreguiça, te olha tipo "ah, é você" |
| Gasto pequeno | Joinha rápido |
| Gasto médio | Sobrancelha levantada |
| Gasto grande | Olho arregalado, queixo cai até o chão, som de queda |
| Gasto MUITO grande | Tela treme, Jota desmaia, tela "JOTA DESMAIOU. APERTE PARA REANIMAR" |
| Bater meta | Confetes, Jota pula, mergulha no cofre tipo Tio Patinhas, joinha pra câmera |
| Fechar app sem registrar | Notificação: "VOLTA AQUI!" |
| Botão "Eu Resisti" | Cara de orgulho extremo, lágrima, "meu pequeno gafanhoto" |
| Long press no Jota | Ele ri ou reclama "para de me cutucar" (fala diferente cada toque) |
| Shake do celular | Cai pra trás dramaticamente: "AAAH PARA" |
| Erro de digitação (valor absurdo) | "Você digitou R$ 999.999. Tem certeza? Você é o Elon Musk?" |
| Furar meta | Aparece chorando no canto do cofre vazio, plaquinha "socorro" |

## Princípios de animação
- **Squash & stretch** real — cards balançam ao toque
- **Peso** — botões afundam quando pressionados
- **Exagero** — confetes, fogos, balões over-the-top
- **Som** — moedinha caindo em interações-chave
- **Shake da tela** quando gasta acima da meta
