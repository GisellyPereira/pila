# Imagens de apresentação do Pila

Capturas reais enviadas por Giselly em 3 de outubro de 2026, com o app em modo de demonstração. Os arquivos originais estão em `../screenshots/iphone/`.

As composições seguem o tratamento já utilizado no portfólio para Cook: fundo neutro `#E9E5DF`, capturas completas lado a lado, molduras arredondadas e sombras suaves. As telas não foram recriadas nem tiveram seus textos ou valores alterados. Os SVGs incorporam as capturas originais; os PNGs são exportações para exibição no GitHub.

| Arquivo | Uso | Dimensões |
| --- | --- | --- |
| `pila-cover.png` | Capa do README com nome e identificação das telas. | 1760 × 1060 |
| `pila-portfolio.png` | Capa 16:10 para o portfólio, sem nome ou legendas sobre a composição. | 1760 × 1100 |
| `visao-geral-e-gastos.png` | Detalhes de acompanhamento e registro. | 1600 × 1200 |
| `agenda-e-planejamento.png` | Detalhes de agenda e simulação. | 1600 × 1200 |

Fontes vetoriais com os mesmos nomes estão nesta pasta. A marca vem de `../../mobile/assets/brand/pila.svg`. Nenhum aplicativo foi iniciado para produzir estas composições.
